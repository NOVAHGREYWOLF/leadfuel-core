## Design as built (so the tests and doc match)
- Local only by construction: ids resolve only through engines whose key AND `.name` are in `LOCAL_ENGINES={"local"}`; other engines are never called (not `models`, `available`, `stream`). Unknown id is refused (`not_installed`), cloud-looking id refused (`not_local`). No switch for a cloud model; that is a later owner decision and would need the spend gate (cost x lanes).
- Sequential, one lane at a time: `LocalEngine` has one `_live_response` and one level-triggered `_cancel` flag per instance, and a model swap costs about 25 s (`lfdesk/engine/README.md`). 2 to 4 models.
- `tools=None, on_tool=None`; a tool chunk is ignored with warning `UNEXPECTED_TOOL_USE`.
- Lane states: queued, running, done, error, cancelled, skipped, incomplete (stream ended with no terminal chunk is `incomplete`, never `done`).
- Cancel safety: `_interrupt` calls `engine.cancel()` only while a lane is in flight (marker under `run._ilock`); the lane clears the marker at its terminal chunk then `gen.close()`s. `stop` sets the flag then takes `_ilock`; the lane reads the flag and marks in flight under `_ilock`, so one always sees the other (`stopped_early` path never calls the engine). Residual window, state it in the doc: an engine that raises in the same microseconds as a user stop could leave the engine's cancel flag set for the next turn.
- Nothing written until the owner picks: `gate.compare_pick` writes user message, then the chosen answer, once (`mark_picked` claims first; failure gives the claim back; retry reuses `run.conv_id`, `user_written`, `assistant_msg_id`).
- `build_gate(api, scripted)`: allow-list adds `"fake"` only when `scripted` (the app registers `engines["fake"]` unconditionally, Assistant.py line 275). Blocker = a live `api._turn`. Lease tell = `api.panes.turn_started/turn_finished` (as `Api._lease_watch`). System prompt = `api._chat_prompt_context(conv_id, history)`.
- Not in v1, say so in the doc: memory, skills, project files, images (they have per-turn side effects I did not verify), per-lane timeout (Skip and Stop instead), parallel lanes, persisting a comparison across restarts (it lives in memory; only the pick is saved), a cloud lane.
