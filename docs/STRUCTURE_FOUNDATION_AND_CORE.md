# Structure: foundation plus company, and whether the core is open (webchat-12)

Status: decision record, default applied. Written 2026-11-23 by the COUNSEL desk. Nothing here
publishes, transmits or spends, and no legal text is drafted for filing.

## What the chat proposed (source: WEB-CHATS.md webchat-12, 2026-11-13, "Open source tool for code")

- A foundation that owns the name and the promise.
- A company that sells boxes and support.
- An open source core.
- It also found that the 37 tab Document Set describes a hosted service with staff access, which
  conflicts with local first. No decision was taken in the chat.

## Decision applied (owner pre-decided on his standing words; classification row webchat-12, default B1)

1. **The core stays closed.** No source is opened, no licence file is added, no repo is made
   public because of this record. Nothing in this repository changes visibility.
2. **A counsel task is queued** (below). Counsel decides what we are willing to claim; this record
   does not describe a structure we intend to build as if it existed.
3. **The Charter and Security Policy tabs of the 37 tab Document Set are for the hosted tier
   only.** A local NovahOS install has no staff access to the owner's data, so those tabs must not
   be read as describing it. Marking them is a text change in the Document Set, which is not in
   this repository; the instruction is recorded here so whoever holds that set applies it.

## The counsel task (queued, not started)

Owner: COUNSEL (what we say, to someone who will hold us to it). Done when counsel has written,
for owner review and with nothing published:

- what a foundation could and could not own (the name, the promise) against a company that sells
  boxes and support, and whether the two are needed before customer one;
- a one page note on what "closed core" means for a buyer reading a procurement questionnaire;
- the hosted-tier-only wording for the Charter and Security Policy tabs;
- a list of which of those claims the code can show today (a claim we cannot show is a claim we
  should not make).

Not counsel's: whether a claim is true (PRIVACY, VAULT), page copy (SURFACE), whether an outward
path is gated (DOORS).

## What would reopen this

An owner decision to open the core. That is a separate card with its own licence, trademark and
contribution questions; it is not implied by this record.
