Sessions desk

Every local session, filed by sidebar group: what it is doing and how far it is toward done. A keeper refreshes it every 30 minutes. Nothing here archives, stops or messages a session; flagged sessions go to the router.

Keeper digests

Times are Pacific. Size is the session's context window against its handoff cap (300k; 120k for Haiku). The app reports size only for a running session, so a stopped one shows its last reading or unknown.

Percent toward done counts five milestones: PR open, checks green, PR merged, STATUS: DONE reported, nothing unpushed. It reads unknown while any of them is unknown.
